# 10,000 Danfos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Day 26 as a responsive, tested, interactive 10,000-agent traffic engineering game and add it to the challenge dashboard.

**Architecture:** Keep agent state in typed arrays inside a worker-owned simulation runtime, publish transferable render snapshots, store UI state in Zustand, and render the world with React Three Fiber instancing. Expose the supplied search, routing, visualization, benchmark, replay, tour, audio, and sharing controls without adding new subsystems.

**Tech Stack:** Vite 8, React 19, TypeScript 6, Three.js, React Three Fiber, Drei, Zustand, Tailwind CSS 4, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-25-10000-danfos-design.md`

## Global Constraints

- Preserve 10,000 visible agents, instanced rendering, real search counters, grid-vs-naive correctness, pointer interaction, roadblock rerouting, and a device-safe benchmark.
- Use `day-26-10000-danfos` for the branch, directory, package, and expected Vercel slug.
- Push once after scaffolding and after each subsequent batch of five edited files; push a final partial batch.
- Keep the city stylized and describe traffic/geometry as synthetic.
- Do not overwrite the untracked Day 25 planning files in the repository root.
