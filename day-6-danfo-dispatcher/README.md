# Danfo Dispatcher

Day 06 of the 30 Days Building challenge: a real-time 3D Lagos transport
simulation built with React, TypeScript, Vite, Three.js, React Three Fiber,
Drei, Motion, and Tailwind CSS.

## Run locally

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm build
pnpm lint
```

Select a danfo on the city grid, dispatch it to a destination, manage queues,
survive traffic and incidents, and keep Lagos moving.
